# Library Management System — Object Oriented Analysis & Design

A comprehensive Object-Oriented Analysis (OOA) and design modeling project for a simplified Library Management System.

## Features

- Book Management
- Member Management
- Borrow/Return Workflow
- Fine Management
- Search Books

## Tech Stack

- Python 3.x
- Object-Oriented Analysis & Design
- UML Diagrams

## How to Run

```bash
python src/main.py
```

## Business Rules

- Maximum 5 books per member
- Borrow period: 14 days
- Fine: $0.50/day
- Book must be available
