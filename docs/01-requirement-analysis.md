# Requirement Analysis

## Project Description

The Library Management System is designed to help librarians manage books, members, borrowing, and returning operations efficiently.

---

# Main Actors

## Librarian
- Adds books
- Removes books
- Issues books
- Receives returned books

## Member
- Searches books
- Borrows books
- Returns books

## Admin
- Manages the entire system
- Generates reports

---

# Functional Requirements

- Add books
- Update books
- Remove books
- Register members
- Search books
- Borrow books
- Return books
- Calculate fines

---

# Non-Functional Requirements

- User friendly
- Secure
- Fast search functionality
- Easy maintenance
- Scalable architecture

---

# Business Rules

- A member can borrow a maximum of 5 books
- Borrowing period is 14 days
- Overdue fine is $0.50 per day
- Books must be available before borrowing
